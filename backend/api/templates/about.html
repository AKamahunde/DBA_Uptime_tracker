About

The Database Management Hub was developed to assist Database Administrators (DBAs) in reporting on key database performance metrics like uptime, for compliance and auditing purposes, and general improved reporting across Oracle, MySQL, PostgreSQL, and Microsoft SQL Server environments.

System Modules

Dashboard Overview

Consolidated operational view tracking overall availability, MTTR, planned/unplanned downtime, replication status, and SLA compliance metrics.

Incident Register

Records unplanned outages. Ongoing incident durations are calculated automatically in the background until resolved, preventing human tracking gaps.

Backup & Recovery

Tracks backup success rates, backup storage types, and recovery test results to validate disaster recovery (DR) preparedness and database durability.

Maintenance Register

Records planned maintenance such as upgrades, patching, OS reboots, or hardware migrations without contributing to unplanned outage metrics.

Capacity Tracking

Tracks database storage growth trends, identifies the largest tables, and calculates projected storage exhaustion dates for proactive scaling.

Replication & Health

Monitors lag times and CPU/Memory/Disk performance stats across the Oracle, MySQL, MS SQL, and PostgreSQL environment fleets.

Security & Data Integrity

Standard Users

Can view dashboards, create operational records, and view the audit trail. Handled by a strict 5-minute edit rule to protect logs (records become read-only after five minutes).

Administrators

Retain full create, edit, delete, and role management permissions. Can override the five-minute edit window to modify historical logs when necessary.

Immutable Change Timeline

Every single modification made to an incident is permanently logged in the History Timeline (captures editor, timestamps, status transition, and comments). Change history cannot be modified or deleted.

System Information

Version: 2.3.0

Architecture: Django 6.0.7 / MySQL

Integrations: Built with an extensible ETL pipeline for Kafka and REST APIs.
