About Uptime Tracker

Uptime Tracker is the central operations hub and logging platform for Database Administrators. It is designed to track, monitor, and report on the critical infrastructure that keeps the organization's data running.

Modules

  • Incidents: Log and track database incidents and outages.
  • Replication: Monitor master-replica replication health.
  • Backup & Restore Register: Track all database backup and recovery operations.
  • Server Health Registry: Monitor server CPU, memory, disk, and connection metrics.
  • Maintenance: Log scheduled maintenance activities and change records.
  • Capacity Tracking: Track database growth, disk usage, and future planning.

System Information

Version: 2.2.0

Architecture: Django 6.0.7 / MySQL

Integrations: Built with an extensible ETL pipeline for Kafka and REST APIs.
